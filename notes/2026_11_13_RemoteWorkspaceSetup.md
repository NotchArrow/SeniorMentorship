# Remote Workspace Setup | 2026 11 13
After working for a few shorter sessions across November 6th, November 11th, and November 13th, the remote working setup is almost complete. When in person at Jefferson Lab, the working laptop is directly integrated into the internal network. It's directly authorized to access the lab's servers, so using the local models is relatively straightforward after initializing an API key. The models at Jefferson Lab can access internal information and communicate via Codex or Claude Code as a harness.

However, accessing the models for remote work is a difficult process. By using a Linux environment, the research group was able to setup a proxy to authenticate the devices and connections, even though the communication doesn't originate from the internal network. It uses the ssh protocol to sign into the lab servers, and then a proxy and Docker container that route the traffic to the correct services and run them. After all of those are setup and authenticated to send and receive traffic, a bin script launches Codex with the local model.

The setup is almost complete, but my local environment has not granted access permissions to the Codex harness yet. It should be a pretty simple fix, but the harness will have to be contained so that the model cannot run sensitive commands or access other parts of the system while it is working. Once the setup is fully complete and secured, remote work for Jefferson Lab can continue frequently, even when traveling is impractical or the lab is closed.
